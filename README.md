# Cloud
☁️ Cloud — the distributed file browser for Republicka's CC0 public domain archive. Browse, search, preview, and stream straight from the manifest — no backend required. 🗂️🔍🎧🎬🖼️ Three built-in themes (day/night/festival ✨), inline audio &amp; video playback, one-click link copying, and full offline save-and-go. Free forever, CC0. 🌐💾
